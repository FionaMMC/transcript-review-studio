# Product tour — elevenlabs.io

**[Watch the English product tour](product-tour-elevenlabs.mp4)** — 69.9 seconds, 1920 × 1080, with English captions. If GitHub displays a file-download screen, choose its raw/download control and open the MP4 locally.

The tour shows local candidate transcripts, confidence-assisted prioritisation, human review anywhere in the recording, corrections, qualitative-analysis exports and the sample walkthrough. It uses the actual app's public practice workspace. No research interviews, private transcripts or database files are included.

## Demonstration boundaries

The tour is edited and includes held frames; it is not a processing-speed benchmark. Both candidate passes use the same model. The practice correction is deliberately seeded and saved as pending, not presented as a certified transcription result. The app assists preparation for qualitative analysis; it does not perform automatic research coding or guarantee compatibility with every analysis-software version.

The original public source video is bundled separately in [samples/lua-workshop](../../samples/lua-workshop/README.md), where beginners can reproduce the workflow locally.
